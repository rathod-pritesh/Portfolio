# Pritesh Rathod API Documentation

Public RESTful API surface providing access to projects, skills, education, and contact services.

## API Endpoints

- `GET /health`: Health status.
- `GET /api/home`: Hero section profile.
- `GET /api/about`: Developer background and bio.
- `GET /api/skills`: Structured skill categories.
- `GET /api/projects`: Featured software projects.
- `GET /api/certifications`: Professional certifications.
- `GET /api/education`: Academic timeline.
- `POST /api/contact`: Send a contact message.
