Pritesh Rathod API Documentation

Machine and developer reference for programmatic access to projects, skills, and portfolio services.

Base URLs

  • Production API: https://portfolio-i5x9.onrender.com
  • Frontend Edge Proxy: https://priteshrathod.vercel.app/api

  • OpenAPI 3.1.0 Specification: /openapi.json (YAML)
  • Agent Authentication Guide: /auth.md
  • ARD Discovery: /.well-known/ard.json
  • RFC 9727 API Catalog: /.well-known/api-catalog
  • MCP Server Card: /.well-known/mcp/server-card.json

Endpoints Summary

Method Path Description
GET /health API health check and heartbeat status
GET /api/home Hero profile summary, title, and social links
GET /api/about Bio, background, and academic history
GET /api/skills Categorized technical skills (Python, Go, LangChain, RAG)
GET /api/projects Showcase projects with tech stacks and GitHub links
GET /api/certifications Credentials from Anthropic, Google, IBM, AWS
GET /api/education Educational timeline (M.Sc., B.Sc.)
POST /api/contact Submit a contact message (name, email, message)

Quickstart Request Example

curl -s https://portfolio-i5x9.onrender.com/api/projects | jq .

Sending a Contact Message

curl -X POST https://portfolio-i5x9.onrender.com/api/contact \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe",
    "email": "jane@example.com",
    "message": "Interested in collaborating on a FastAPI project!"
  }'
