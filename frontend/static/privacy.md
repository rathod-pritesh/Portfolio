# Privacy Policy

Last updated: September 29, 2026

## Overview

This privacy notice explains data handling practices on `priteshrathod.vercel.app`.

## Data Collection

- **Contact Inquiries**: Information submitted via contact forms or the `POST /api/contact` API (name, email, message) is collected solely to respond to communications.
- **Server Logs**: Web requests may temporarily log IP addresses and user agents for security, debugging, and traffic verification.
- **Third Parties**: Personal data is never sold or shared with advertisers.
